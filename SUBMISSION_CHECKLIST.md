# Piazza submission checklist

## Included in this package

- Complete Node.js/Express REST API
- MongoDB/Mongoose user and post models
- JWT authentication on all protected resources
- Input validation and consistent error handling
- Post creation, topic browsing, likes, dislikes and comments
- Live/expired status and interaction blocking after expiry
- Expired-post history and most-active-post queries
- Automated runner for the 20 coursework test cases
- Postman collection and environment
- Dockerfile and Docker Compose configuration
- Kubernetes Deployment with five replicas and LoadBalancer Service
- Technical report draft in DOCX and PDF
- Evidence folders with instructions for adding genuine screenshots

## You must complete before final submission

1. Replace all bracketed student details in `docs/Piazza_Technical_Report.docx`.
2. Run the application and the 20-case test runner.
3. Capture your own Postman/test screenshots and place them in `evidence/postman`.
4. Deploy your own repository to the VM and capture genuine evidence in `evidence/vm`.
5. Build/push your own Docker image and update `kubernetes/deployment.yaml`.
6. Deploy your own Kubernetes cluster, confirm five replicas and the LoadBalancer, and capture genuine evidence in `evidence/kubernetes`.
7. Update the report with your real URLs, IP addresses, image name, screenshots and observations.
8. Add a sensible Git commit history and push the final repository.
9. Remove `.env` and every real secret before submission.
10. Read and understand the code so you can explain it during a demonstration or viva.
